Umbra Live: bring your own data

The engine's tests run here in your browser. Drop in a new data layer and it becomes a new test or a filter on every test; drop in a list of sites and the engine scores them. Every map and list re-ranks on the spot.

Drop a file anywhere on this box

Data layer: GeoTIFF in latitude/longitude, CSV with lat, lon and a value column, GeoJSON points, or ESRI ASCII grid (.asc).

Site list: CSV with name, lat, lon. Each site gets a percentile on every test.

Find look-alikes: click any spot on the map, or pick a Moon or Mars fingerprint, and the engine finds every place on Earth that matches it across all ticked layers, including the ones you dropped in.
